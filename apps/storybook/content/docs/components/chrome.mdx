用 `Layout` 组织会话侧栏、移动端抽屉和页头，用 `Chat` 承载消息与输入区。在此基础上接入
信息栏、会话操作确认、工具审批、连接状态、欢迎态和失败重试。

```tsx
import {
  AgentHeader, Chat, ConfirmDialog, FileCard, Layout, SessionSidebar, StatusIndicator, SubAgentPanel, ToolApprovalCard,
} from "@openagentpack/kit-chat-ui";
```

copy-in 接入（复制后 import 改为项目内路径）：

```bash
pnpm kit:add layout
pnpm kit:add chrome
pnpm kit:add chat
pnpm kit:add session-sidebar
pnpm kit:add menu
pnpm kit:add prompts
pnpm kit:add tool-approval
pnpm kit:add sub-agent-panel
pnpm kit:add file-card
pnpm add @radix-ui/react-dialog @radix-ui/react-alert-dialog @radix-ui/react-dropdown-menu
```

`chrome` 批量复制页头、状态灯、确认弹窗、空态、错误态和子线程兼容面板。
渲染依赖见 [Markdown 接入](/docs/components/feedback/markdown#接入)，主题配置见 [组件总览](/docs/components#主题)。
交给 coding agent 接入时使用 [kit-components Skill](/docs/skill/kit-components)。

## 何时使用

- 将会话目录、页头和聊天区组合为桌面与手机共用的对话页。
- 在归档或删除会话前展示操作影响，并取得用户确认。
- 展示欢迎、加载、重连与错误重试状态。

## 代码演示

预览使用本地数据。演示面板内可切换设备视口、查看源码和复制接入命令。

### 页面骨架（含破坏性动作确认）

可新建或切换会话，从行尾「更多操作」打开归档或删除确认。切换到手机视口后，从页头打开会话抽屉。

<Showcase name="chrome" />

### 信息栏

信息栏通过 `Layout.aside` 展示 Agent 信息、子 Agent、技能与 MCP、工具、记忆库和产物。
点击页头「资源」可展开或收起面板。各分区支持折叠，子 Agent 的任务行可打开执行记录。
切换到手机视口后，点击「资源」打开全屏面板。

<Showcase name="resource-panel" />

`Layout` 提供响应式外壳，`SubAgentPanel` 展示子 Agent 分区，`FileCard` 绑定产物的预览与下载。
预览中的文件操作显示本地回调结果。完整资源分区由业务页面组合，体验页实现位于
`apps/web/src/features/chat/aside-panel.tsx` 的 `AsidePanelSections`。
[Layout 右栏接口](/docs/components/layout#api)

### 工具审批

点击「查看参数」核对文件写入路径和内容，再选择「允许」或「拒绝」。示例会显示提交的决定，
点击「重置示例」可以试另一种结果。

<Showcase name="tool-approval" />

在对话页中，通过 `Chat.approvals` 展示审批卡，将 `chat.canSend` 传给 `Chat`。
等待审批时仍可编辑草稿，发送暂时禁用。 [工具审批接入](/docs/sdk/tool-approvals)

### 状态灯

`phase` 与 `connection` 组合区分已连接、生成中、等待审批、正在停止、已中断、重连中与错误。

<Showcase name="status" />

将 `chat.phase`、`chat.connection` 和 `chat.streamError` 分别传给 `phase`、`connection` 和 `error`。
页头可使用紧凑的 `variant="badge"`，长错误截断显示，完整内容保留在 `role="status"` 文本中。

### 子 Agent 执行过程

将 `useChat().multiAgent` 传给 `Chat`，子 Agent 的任务会在主消息流中显示为可展开的卡片。
点开卡片后可以查看只读历史、加载更早消息，并重试失败的历史请求。

<Showcase name="multi-agent" />

体验页的信息栏也展示子 Agent 的派发记录。按名称展开后，点击任务可打开执行记录弹窗。
[SubAgentPanel 资源面板示例](/docs/components/general/sub-agent-panel#执行记录弹窗与历史加载)

### 欢迎、加载与错误态

`EmptyState` 展示欢迎、空目录和加载态，`ErrorState` 展示请求失败或 Agent 不可用等状态。

<Showcase name="states" />

欢迎态可将 `EmptyState` 和 `Prompts` 放进 `Chat.empty` 的同一容器，输入框保持挂载。
`ErrorState` 传入 `onRetry` 后显示重试按钮。示例问题的配置见 [Prompts](/docs/components/wake/prompts)。

## 接入

属性类型、必填项和回调见 [组件 API 参考](/skills/kit-components/references/api.md)。

### 组合对话页

给 `Layout` 的外层容器明确高度，例如 `h-dvh`。将 `SessionSidebar` 放入 `sidebar`，将页头放入
`header`，再把 `menuToggle` 传给 `AgentHeader.leading`。切换会话后调用 `closeSidebar()` 收起移动抽屉，
用 `Chat` 展示选中会话的消息与输入框。完整的数据绑定见 [三栏对话页示例](/docs/sdk/experience#组件绑定示例)。

### 会话操作确认

归档或删除会话前先向服务端请求计划，在具有 `role="alertdialog"` 语义的 `ConfirmDialog` 中展示返回的
`diff`。用户显式确认后，携带 `plan_id` 和一次性 `confirm_token` 执行操作。空或畸形令牌返回
`400 invalid_request`，重放已消费的令牌返回 `428 confirmation_required`。 [会话操作计划](/docs/api/kit/sessions/sessionid/plan/post)

通过 `Layout.dialogs` 渲染确认弹窗。待确认状态由调用方保存，移动抽屉打开时也能将焦点交给弹窗。
`SessionList` 的会话标题按钮与行尾菜单触发器并列，具体操作由 `menu` 插槽放进弹层。 [Menu 接入](/docs/components/basic/menu)

## 主题变量（Design Token）

引入 `@openagentpack/kit-chat-ui/theme.css` 后使用以下冻结 token。下表列出亮色值，
暗色由 `data-kit-theme="dark"` 使用对应色板。

| Token | 用途 | 默认主题 | 工作区主题 |
| --- | --- | --- | --- |
| `--kit-accent` | 生成中、连接中与重连中的状态色；中性确认按钮底色 | `#4f46e5` | `#171717` |
| `--kit-danger` | 失败、中断与错误状态色；危险确认按钮底色；ErrorState 图标与标题 | `#dc2626` | `#ad372f` |
| `--kit-accent-fg` / `--kit-danger-fg` | 确认按钮文字 | `#ffffff` | `#ffffff` |
| `--kit-warning-fg` | 等待审批状态色 | `#b45309` | `#805917` |
| `--kit-fg-muted` | 空闲与停止状态色；说明文字与弹窗正文 | `#5b6478` | `#737373` |
| `--kit-bg-subtle` | 状态徽标和空态加载标记底色 | `#f6f7fb` | `#f7f7f7` |
| `--kit-border` | 弹窗与取消按钮描边 | `#e3e6ef` | `#e5e5e5` |
| `--kit-border-subtle` | badge 描边；ErrorState 描边；默认主题下等于 `--kit-border` | `#e3e6ef` | `#ececec` |
| `--kit-surface` | 弹窗与重试按钮底色 | `#ffffff` | `#ffffff` |
| `--kit-overlay` | 弹窗遮罩 | `rgb(0 0 0 / 40%)` | `rgb(23 23 23 / 32%)` |
| `--kit-shadow` | 弹窗投影 | `0 8px 28px rgb(16 19 34 / 8%)` | `0 4px 20px rgb(23 23 23 / 6%), 0 1px 4px rgb(23 23 23 / 4%)` |

badge 圆点闪动消费 Tailwind 内建 `motion-safe:animate-pulse`，遵循系统减少动画偏好；
焦点环走 `--kit-focus`（默认等于 `--kit-accent`）；标题与说明使用 `--kit-text-title` /
`--kit-text-heading` / `--kit-text-label` / `--kit-text-caption` 文字档位。弹窗圆角使用
`--kit-radius`，按钮圆角使用 `--kit-radius-sm`。更多主题配置见
[组件总览](/docs/components#主题)。
