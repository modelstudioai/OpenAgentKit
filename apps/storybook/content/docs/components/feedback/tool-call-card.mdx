---

`ToolCallCard` 展示单个工具调用的摘要与状态，展开后可查看输入参数和结果。
工具执行与审批由业务方接入。

```tsx
import { ToolCallCard } from "@openagentpack/kit-chat-ui";
```

copy-in 接入（复制后 import 改为项目内路径）：

```bash
pnpm kit:add tool-call-card
```

渲染依赖见 [Markdown 接入](/docs/components/feedback/markdown#接入)，主题接入见 [组件总览](/docs/components#主题)。

## 何时使用

- 在消息或执行记录里单独展示工具调用。
- 需要用户查看参数并作出批准或拒绝时，使用 [ToolApprovalCard](/docs/components/feedback/tool-approval)。

## 代码演示

### 工具卡三态

状态取 `running`、`done` 或 `error`。SDK 按调用 ID 匹配后到的输出，更新原来的工具卡。
JSON 对象及数组使用代码高亮，其余输出按等宽文本展示。缺少参数和结果时显示「暂无调用详情」。

## API

### ToolCallCard

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `part` | 必填，`tool` 类型的 [MessagePart](/docs/components/general/message#messagepart) | `ToolPart` | — |
| `className` | 追加到根 `details` 的工具类 | `string` | — |
| `contentMaxHeight` | 替换展开内容的限高，`max-h-none` 可取消限高 | `string` | `"max-h-80"` |

## 主题变量（Design Token）

结构化输出的高亮样式见 [CodeHighlighter](/docs/components/feedback/code-highlighter#主题变量design-token)。
