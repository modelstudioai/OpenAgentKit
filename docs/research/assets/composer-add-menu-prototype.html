演示 chat-ui 组件组合出业务输入框工具栏的效果。「添加」菜单 = Menu 包装层扩展 （MenuSeparator / MenuSub / MenuSubTrigger / MenuSubContent + MenuItem 结构化插槽）；连接器 = MenuLabel / IconStack / Switch 三个新导出的组合， 触发钮空态圆钮 ↔ 已选堆叠胶囊的形态派生全在业务侧。

业务方使用示例

菜单词条、点击行为、数据源全部在业务侧；组件层只提供形态。选中技能插入 /name 标记，与 / 触发的 Suggestion 共用同一份技能数据。 

import {
  Menu, MenuTrigger, MenuContent, MenuItem, MenuSeparator,
  MenuSub, MenuSubTrigger, MenuSubContent,
  type SenderRef,
} from "@openagentpack/kit-chat-ui";

function AddMenu({ skills, senderRef, onPickFile }: {
  skills: Array<{ id: string; name: string; icon: ReactNode; description: string }>;
  senderRef: RefObject<SenderRef | null>;

}) {
  const { t } = useTranslation("chat"); // 菜单词条归业务 i18n，组件词典不含
  const insertSkill = (name: string) =>
    senderRef.current?.replaceRange(caret, caret, `/${name} `);

  return (
    <Menu>
      <MenuTrigger asChild>
        <button type="button" aria-label={t("add.trigger")}><PlusIcon /></button>
      </MenuTrigger>
      <MenuContent side="top" className="w-60">
        <MenuItem icon={<PaperclipIcon />} onSelect={onPickFile}>
          {t("add.file")}
        </MenuItem>
        <MenuSeparator />

        <MenuSub>
          <MenuSubTrigger icon={<PackageIcon />}>{t("add.skills")}</MenuSubTrigger>
          <MenuSubContent className="w-[300px]">
            {'/* active 由业务从 sender 草稿派生：草稿删除 /name 标记后自动回到 false */'}
            <div className="max-h-[173px] overflow-y-auto overscroll-contain">
              {skills.map((s) => (
                <MenuItem key={s.id} icon={s.icon} description={s.description}
                  active={draftSkills.includes(s.name)}
                  onSelect={() => insertSkill(s.name)}>
                  {s.name}
                </MenuItem>
              ))}
            </div>
            {'/* 固定操作区：不随列表滚动，与选项区用组合表达 */'}
            <MenuItem className="text-[length:var(--kit-text-meta)] text-[var(--kit-fg-muted)]"
              onSelect={viewAllSkills}>
              {t("add.viewMore", { count: 8 })}
            </MenuItem>
            <MenuSeparator />
            <MenuItem icon={<SettingsIcon />} onSelect={manageSkills}>
              {t("add.manageSkills")}
            </MenuItem>

            {t("add.agent")}
          </MenuSubTrigger>
          <MenuSubContent>{/* Agent 面板：业务组合 */}</MenuSubContent>
        </MenuSub>
      </MenuContent>
    </Menu>
  );
}

连接器：触发钮空态/已选形态由业务派生；行内 Switch 是纯视觉指示（不嵌套交互元素）， 点整行切换、preventDefault 保持菜单打开。 

import {
  Menu, MenuTrigger, MenuContent, MenuItem, MenuSeparator, MenuLabel,
  IconStack, Switch,
} from "@openagentpack/kit-chat-ui";

function ConnectorMenu({ connectors, picked, toggle, manage }: {
  connectors: Array<{ id: string; name: string; logo: ReactNode }>;
  picked: string[];
  toggle: (id: string) => void;
  manage: () => void;
}) {
  return (
    <Menu>
      <MenuTrigger asChild>
        {'/* 空态 = 圆形图标钮；已选态 = 同一钮内渲染 IconStack，形态派生全在业务 */'}
        <button type="button" className={roundBtn} aria-haspopup="menu">
          {picked.length === 0
            ? <PlugIcon className="size-4" />
            : <IconStack items={picked.map((c) => c.logo)} max={3} />}
        </button>
      </MenuTrigger>
      <MenuContent side="top" className="w-[310px]">
        <MenuLabel>{t("connector.title")}</MenuLabel>
        <MenuSeparator />
        <div className="max-h-[216px] overflow-y-auto overscroll-contain">
          {connectors.map((c) => {
            const on = picked.includes(c.id);
            return (
              <MenuItem key={c.id} icon={c.logo}
                role="menuitemcheckbox" aria-checked={on}
                onSelect={(e) => { e.preventDefault(); toggle(c.id); }}
                trailing={
                  {'/* 行内开关纯视觉：不嵌套交互元素，点击整行切换 */'}
                  <Switch checked={on} aria-hidden tabIndex={-1} className="pointer-events-none" />
                }>
                {c.name}
              </MenuItem>
            );
          })}
        </div>
        <MenuSeparator />
        <MenuItem icon={<SettingsIcon />} onSelect={manage}>
          {t("connector.manage")}
        </MenuItem>
      </MenuContent>
    </Menu>
  );
}

协议边界

  • 组件层无「技能 / 知识 / MCP」语义；词条、行为、数据全在业务侧。
  • 「选项区滚动 + 操作区钉底」= 组合（滚动 div + MenuSeparator），不引入组件概念。
  • 面板默认 kit token（--kit-radius-sm 9px 等）；设计稿 16px 圆角等由业务 className 覆盖。
  • 键盘导航、typeahead、Escape、焦点圈由 Radix 提供；本原型演示鼠标路径 + Escape。
  • 「查看更多 (N)」「管理技能」与普通条目同构（anatomy 相同），钉底是分区组合的结果。
  • SubTrigger 内置 chevron 只是 trailing 缺席时的默认值：业务传 trailing 即接管右侧（换图标、换形态都走这一个插槽）；chevron={false} 用于既不传 trailing 也不要指示。
  • MenuItem 的 active? 是业务派生的选中态（如从 sender 草稿扫描 /name 标记），组件不感知 sender；选中勾同样是 trailing 缺席时的默认值，样式经 data-active 钩子覆盖；定义 active 后角色升级为 menuitemcheckbox + aria-checked。
  • Switch 在菜单行内是纯视觉指示（业务传 aria-hidden + pointer-events-none + tabIndex={-1}，守「不得嵌套交互元素」），点击整行切换、状态业务持有；独立使用时自身可交互（Space/Enter）。
  • 多选行切换不关菜单：Radix Item 选中默认关闭，业务在 onSelect 里 preventDefault（文档化模式，组件不加开关 prop）。
  • 连接器触发钮空态（圆钮）/ 已选（IconStack 胶囊）形态由业务派生，组件不做形态枚举；堆叠条目 aria-hidden，名称靠按钮 aria-label 表达。
